# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub's **Security** tab by
opening a private vulnerability report. Do not include credentials, personal
financial data, or exploit details in a public issue.

Include the affected component, reproduction steps, expected impact, and any
suggested mitigation. Reports will be reviewed before public disclosure.

## Secrets

Never commit API keys, passwords, encryption keys, access tokens, or production
configuration. Use environment variables or the deployment provider's secret
store instead.
